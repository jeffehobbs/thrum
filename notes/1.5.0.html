Thrum in Logic Pro

Thrum now carries an Audio Unit instrument. In Logic (or any AUv3 host), pick AU Instruments → Jeff Hobbs → Thrum on a Software Instrument track and play the drone from a keyboard: the same eight timbres, temperaments and thirty-second room, with every control automatable and a preset per timbre.

  • Just intonation is tuned to the Key control, and key or temperament changes glide the sounding tones.
  • Drone or Accent articulation; mod wheel for jawari, CC11 for swell, sustain pedal, ±2 semitone bend.
  • Flow, as an option. Switch it on and the unit plays itself, clocked by rendered audio so bounces match real time. Its moves show on the host's parameters for automation, and any control you touch is left alone for five minutes.

Launch Thrum once after updating so macOS registers the unit. If Logic doesn't list it, use Plug-in Manager → Reset & Rescan.
